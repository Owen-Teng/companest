# 展示、体验与源码 / Showcase and source access

本目录公开介绍伴境 Companest 的创意、界面与当前邮件能力，方便个人主页访客了解项目。这里不是可安装源码发行包。

## 当前获取方式

- 产品源码仍在私有仓库中，尚未开放公众下载或发布正式安装包。
- 已获仓库权限的协作者可以访问[私有发布分支](https://github.com/Owen-Teng/friday/tree/codex/fridayos-mail-preview-r5)，阅读其中的安装和样例体验说明。无权限访客无法打开该入口。
- 产品使用自己的受支持邮箱配置；AI 回信建议需要自己的受支持本机 Codex CLI 环境、登录和额度。
- 邮件记录与草稿保存在使用者本机。请求 AI 建议时，选定上下文会发送到所配置服务。本机存储不等于离线 AI。

## 展示材料的边界

界面示例均使用独立虚构数据。没有发布作者的真实邮箱连接、邮件、凭据、运行数据库或私有工程历史。场景动画不证明业务已经接通，截图分镜不是连续录屏。

本次公开展示不授予产品源码或媒体新的开源许可证；进一步分发或复用应按相应权利条件处理。
